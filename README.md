#  Breast Cancer Classification using Machine Learning

##  Project Overview

This project is a **Machine Learning classification project** that uses four different classification algorithms to predict breast cancer outcomes:

* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)
* Decision Tree
* Random Forest

The **Breast Cancer Wisconsin dataset is loaded directly from the scikit-learn library** using `load_breast_cancer()`.

The project trains each model, compares their accuracy, identifies the best-performing model, and evaluates it using a confusion matrix and classification report.

##  Objectives

* Learn Machine Learning classification techniques
* Load a dataset using the scikit-learn library
* Split the dataset into training and testing sets
* Apply feature scaling
* Train multiple classification models
* Compare model accuracy
* Select the best-performing model
* Generate a confusion matrix
* Generate a classification report

##  Dataset

The dataset is **loaded from the scikit-learn library**:

```python
from sklearn.datasets import load_breast_cancer

data = load_breast_cancer()
```

The Breast Cancer Wisconsin (Diagnostic) dataset contains features calculated from digitized images of breast mass samples.

### Target Classes

| Target | Class     |
| ------ | --------- |
| 0      | Malignant |
| 1      | Benign    |

> **Dataset acknowledgement:** The dataset is provided through scikit-learn and originates from the Breast Cancer Wisconsin (Diagnostic) dataset. It was not created by me and is used for educational and Machine Learning practice purposes.

##  Machine Learning Models

### K-Nearest Neighbors (KNN)

Classifies samples based on their nearest neighboring data points.

### Support Vector Machine (SVM)

Finds an optimal decision boundary between different classes.

### Decision Tree

Uses a tree-based structure of decisions to classify the data.

### Random Forest

Uses multiple decision trees together to improve classification performance.
